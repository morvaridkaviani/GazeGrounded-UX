# Dataset card

This repository handles three data sources. Only the first exists today.

## 1. Synthetic demo dataset — `synthetic_demo`

| | |
|---|---|
| **Origin** | Generated by `src/gazegrounded/data/synthetic.py` (seeded, deterministic) |
| **Purpose** | Test and demonstrate the software. **Not research evidence.** |
| **Unit of observation** | Trial = participant × task |
| **Size** | 5 interfaces (2 clean/friction pairs + 1 single), 10 tasks, 12 simulated participants, 120 trials, ~33k gaze samples at 60 Hz |
| **Modalities** | Screenshots (rendered UI specs), AOIs, gaze samples, interaction log, templated feedback, friction labels |
| **Generative model** | Latent severity = designed friction + participant susceptibility + noise → visual search length, revisits, fixation durations, failures, errors, feedback category; labels = noisy binning of the latent severity |
| **Known artefacts** | Effects exist because they were programmed; feedback comes from ~30 templates (NLP scores trivially high); one participant has deliberately poor tracking quality |
| **Privacy** | No real people |
| **Licence** | Same as the code (MIT) |

## 2. UEyes — external, `real`

| | |
|---|---|
| **Origin** | Jiang et al., CHI 2023; Zenodo 10.5281/zenodo.8010312 |
| **Licence** | CC BY 4.0 (attribution required). Not redistributed here. |
| **Content** | 1,980 UI screenshots (web, desktop, mobile, poster), 62 participants, 7 s free viewing, Gazepoint GP3 (60 Hz), 1920 × 1200 display |
| **Unit** | Participant × image (free viewing; no task) |
| **Use here** | Gaze pipeline and training/evaluating the saliency model (RQ1 baseline C) |
| **Not usable for** | RQ2/RQ3 (no tasks, interactions, feedback or friction labels) |
| **Preprocessing** | Fixations re-based per image; screen-normalised coordinates mapped to image pixels assuming letterboxing; invalid (FPOGV ≠ 1) and off-image fixations dropped |

## 3. GazeGrounded study — planned, `real`

| | |
|---|---|
| **Origin** | Own WebGazer study (`study/`), after ethics approval |
| **Participants** | Target ≥ 24 adults; demographics collected minimally and reported in aggregate |
| **Unit** | Trial = participant × task (9 per participant) |
| **Modalities** | Webcam gaze estimates, clicks, timings, SEQ ratings, free-text comments; coded friction labels |
| **Preprocessing** | Off-screen samples invalidated; trials < 60 % valid samples flagged; exclusion rules in `study/protocol.md` |
| **Known limitations** | Webcam accuracy (~100–200 px), variable sampling rate, head-movement drift, static screenshots instead of live sites, convenience sample |
| **Privacy** | Pseudonymous codes; no video; no names/e-mails/IPs; local export by the participant; storage and retention per consent form |
| **Intended use** | Research on human/VLM attention alignment and UX friction |
| **Inappropriate use** | Identifying or profiling individuals; inferring health, cognition or emotion; training commercial attention-tracking products; any use beyond the consent given |
